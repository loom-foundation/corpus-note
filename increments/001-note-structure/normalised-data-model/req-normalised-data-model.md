The corpus's structure (kinds, fields, relations, constraints) is specified in one normalised data model, machine-checkable for well-formedness.
The markdown structure of plain files, frontmatter metadata, and the `## Relations` body section implements the specification as faithfully as the medium allows.
A structural change is modelled in the specification before it is implemented in the notation.
Prose governs meaning; the model fixes structure alone.
